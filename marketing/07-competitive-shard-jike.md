# 即刻碎片 · 对标拆解（配合 v0.22.0 发布，周四/周五发）

## 主碎片（约 300 字）

花两天把 GitHub 上 7 个头部「AI agent 技能管理器」挨个拆了一遍，最大的感受：九月底我立项时这个赛道只有 1 个同类，两个月后桌面应用双雄冲到 7 千星，连讯飞都下场做了企业注册表。

红海了，但我反而更确定该做下去：没有任何一家的机制覆盖国产 agent 的目录矩阵。15 个产品哪家共享目录、哪家要传 zip、哪家直接扫仓库，这些脏活国际项目不会替你做。

拆解借了 4 个机制进 v0.21/0.22：团队清单同步、注意力预算审计（你装的每个技能 description 都在每条消息里烧 token）、先看后装、教会 agent 自己管理技能。拒绝了 3 个：桌面 GUI、企业注册表、56 个 agent 覆盖竞赛。

我的项目现在 2 个星。止损规则提前写好：内容平均阅读不过千就换角度，不堆功能。

完整拆解文档开源在仓库 docs/ 里。 pip install cn-skill-sync

## 短碎片（跟评/转发用，约 80 字）

反直觉发现：装 165 个技能的重度用户，每个技能的 description 都常驻系统提示词，每条消息都在为没在用的技能付费。写了个 audit --residency 按上下文成本排行，第一跑就抓出自己一个 1014 字符的超重 description。
