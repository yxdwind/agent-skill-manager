```markdown
### What

Adds the user-level (global) skill directories for five agents that are not
currently listed in `docs/agents.md`:

| Agent | `--agent` | Project Path | Global Path |
|-------|-----------|--------------|-------------|
| AutoClaw2 | `autoclaw2` | — | `~/.openclaw-autoclaw/skills/` |
| WorkBuddy | `workbuddy` | — | `~/.workbuddy/skills/` |
| Comate / Wenxin Kuaima | `comate` | — | `~/.comate/skills/` |
| QwenWork / Qianwen Office | `qwenwork` | — | `~/.qwenworkcn/skills/` |
| DoubaoWork | `doubaowork` | — | `~/.super_doubao/super-doubao-runtime/workspace/.user_skills/` (macOS)<br>`%LOCALAPPDATA%/DoubaoWork/User Data/Default/.doubaowork/agent_mode/workspace/.user_skills/` (Windows) |

`Project Path` is intentionally left as `—`: the source registry manages
user-level directories only. Please fill in project-level paths if your
compatibility matrix requires them.

### Where the paths come from

Exported from the declarative registry of
[`yxdwind/agent-skill-manager`](https://github.com/yxdwind/agent-skill-manager)
(`src/config/products.py`, MIT, stdlib-only), which tracks 15 domestic AI
agent products and is verified on real macOS/Windows installs
([`docs/product-paths.md`](https://github.com/yxdwind/agent-skill-manager/blob/master/docs/product-paths.md)).
Reproduce with `askill products --json --paths`; the export renders absolute
home paths as portable `~/` / `%LOCALAPPDATA%` forms.

### Deliberately not added

- `TRAE SOLO CN` and `Qoder CN IDE` share `~/.trae-cn/skills/` and
  `~/.qoder-cn/skills/` with the already-listed `trae-cn` / `qoder-cn` entries.
  They are directory aliases, not separate path rows.
- `DuMate` has no filesystem skill directory (managed inside the app via
  uploaded .zip), so it does not fit the `npx skills` install model.

### Notes for maintainers

- QwenWork requires extra SKILL.md frontmatter fields
  (`name`, `version`, `description`, `description_zh`); skills without them
  may not load.
- WorkBuddy / CodeBuddy also gate skills behind `settings.json` switches.
- This PR was generated from a 2026-11-15 snapshot of `docs/agents.md`;
  please re-check for overlap if the file changed since.
```
